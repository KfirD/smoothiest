# Smoothiest

NEAT (Neuroevolution of Augmenting Topologies) implementation for CartPole.

## Links

- [Backprop + NEAT](http://blog.otoro.net/2016/05/07/backprop-neat/)
- [Original NEAT Paper](http://nn.cs.utexas.edu/downloads/papers/stanley.gecco02_1.pdf)
- [Fernando Torres' NEAT Implementation](https://github.com/FernandoTorres)

## Build

```bash
make
```

## Run

```bash
./smoothiest      # 2D version
./smoothiest3d    # 3D version
```
